# Streamlit Vehicle Surface Defect Classification Demo

This package adds a Streamlit interface to the supplied Vision Transformer (ViT)
car-defect classification project. The original `src/` training and inference
files are included unchanged.

## 1. Add your trained model

The supplied `CODE.rar` archive contains source code only; it does not contain
the trained checkpoint. Find the `best.pt` file generated by `src/train.py`.

Either:

- copy it to `outputs/best.pt`, or
- upload it using the checkpoint uploader in the app's sidebar.

The checkpoint must contain `model_state`, as saved by the supplied training code.
The app reads the model name, image size, number of classes and class mapping
from the checkpoint configuration where available.

## 2. Install dependencies

Use Python 3.10 or 3.11 if possible. Open a terminal in this folder and run:

```bash
python -m venv .venv
```

Activate it:

Windows:
```bash
.venv\\Scripts\\activate
```

Linux/macOS:
```bash
source .venv/bin/activate
```

Install the packages:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

For a defence-day setup, install PyTorch and torchvision in advance and test
that they work on the computer you will use.

## 3. Start the application

```bash
streamlit run app.py
```

Streamlit will print a local address, usually:

```text
http://localhost:8501
```

Open that address in your browser.

## Important implementation notes

- The app uses the same 224-pixel default, ImageNet normalization and ViT
  architecture settings as the supplied project; checkpoint configuration
  overrides the defaults.
- It loads the learned checkpoint with `pretrained=False`, avoiding an
  unnecessary download of ImageNet initialization weights.
- It uses `class_to_idx` saved during training to display the correct class
  names. This avoids guessing which numeric output represents each folder.
- The checkpoint is not part of the uploaded archive and must be supplied
  separately.
